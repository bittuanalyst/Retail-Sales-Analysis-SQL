# Retail Sales Analysis – SQL Project

## 📊 Project Overview

An end-to-end SQL project focused on analyzing retail sales data
and converting raw data into actionable business insights.

The project includes relational database design, SQL joins,
aggregations, CASE logic, and business-focused analysis.

## 🎯 Objectives

- Analyze month-wise sales trends
- Identify repeat and one-time customers
- Identify top revenue-generating customers
- Analyze low-performing products
- Understand customer purchasing behavior
- Identify products contributing to negative profit

## 🛠️ Tools & Techniques

- PostgreSQL
- SQL
- Joins
- Aggregations
- CASE statements
- Window Functions
- GROUP BY
- HAVING
- Subqueries
- Relational Database Design

## 📈 Key Insights

### 1. Month-wise Sales Trend

October recorded peak monthly sales of approximately $9K.
Sales varied considerably across months, indicating seasonality
in the dataset.

### 2. Repeat vs One-Time Customers

The analysis identified:

- One-Time Customers: 214
- Repeat Customers: 43

Repeat customers represented approximately 17% of customers.

### 3. Top Revenue Customers

The top 10 customers contributed approximately 17% of total revenue.

The highest contributor in the analysis was Ken Lonsdale with
approximately $2.3K in sales.

### 4. Low-Performing Products

The analysis identified products generating negative profit
despite having sales.

These products can be further investigated for pricing,
discounting, or product portfolio decisions.
